| :--- | :--- | :--- |

* **Technical Integrity**: Completely free from technical errors and broken calculations.
* **Accessibility**: Must open and run smoothly on the judges' machines without requiring unavailable private external connections or proprietary dependencies.
* **Note**: A screenshot inside the written report does **not** replace the actual interactive dashboard file.

### 📝 `README.txt` Specifications
The included `README.txt` must clearly state:
1. **Software name and version** (e.g., *Microsoft Power BI Desktop September 2026 release*).
2. **Step-by-step instructions** on how to open the dashboard file.
3. **User guide** explaining how to navigate features, apply filters, and interpret views.
4. **Required plugins or add-ons** (if any, keeping external dependencies to zero).
5. **Assumptions and limitations** regarding data boundaries or refresh states.

## ⚖️ Important Data Rules & Compliance

* **Malaysia-Centric Data**: All raw data must relate to and originate from Malaysia. Foreign data may only be used to support a comparative statement.
* **Authenticity**: Use genuine, publicly accessible data. **Fabricated, simulated, or fictional data is strictly prohibited.**
* **Bonus Potential**: Official Malaysian government sources (such as OpenDOSM, eStatistik, StatsDW, Tourism Malaysia, and Bank Negara Malaysia) may receive additional evaluation marks.
* **Attribution**: Transparently cite every dataset, API, software library, pretrained model, and external resource used.
* **Privacy**: Do not use confidential, proprietary, or personally identifiable information (PII) without explicit legal permission.
